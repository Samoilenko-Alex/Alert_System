🚨 Kyiv Alert Monitor System
Система автоматического мониторинга воздушных тревог и воспроизведения аудиосигналов для г. Киев. Поддерживает работу с API, планировщик «Минуты молчания» и циклическое воспроизведение сирены.

📁 Структура проекта
monitor.py — Опрос API (UkraineAlarm), создание флагов состояния.

player_service.py — Сервис звука. Реагирует на флаги и играет .wav.

moment_scheduler.py — Планировщик для запуска «Минуты молчания» в 09:00.

alerts_history.json — Лог последних 100 тревог (создается автоматически).

.env — Конфигурация (токены, пути, интервалы).

🛠 Установка и настройка
1. Подготовка окружения
Убедитесь, что установлен Python 3.10+. Создайте виртуальное окружение:

PowerShell
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
2. Конфигурация (.env)
Создайте файл .env в папке alert_monitor/:

Фрагмент кода
ALERTS_TOKEN=ваш_токен_здесь
ALERTS_API_URL=https://api.ukrainealarm.com/api/v3/alerts/31
CHECK_INTERVAL=30
3. Аудиофайлы
Разместите .wav файлы в папке C:\kyiv_alert\silence_moment\:

alarm.wav (Сирена)

cancel.wav (Отбой)

М24_хвилина мовчання.wav (Минута молчания)

🚀 Запуск системы
Для полной работы необходимо запустить три процесса (в разных окнах терминала):

Мониторинг:

PowerShell
python .\alert_monitor\monitor.py
Звуковой сервис:

PowerShell
python .\alert_monitor\player_service.py
Планировщик 09:00:

PowerShell
python .\alert_monitor\moment_scheduler.py
🧪 Тестирование
В папке alert_monitor/ доступны скрипты для ручной проверки звука:

test_moment.py — проверка звука в 09:00.

test_alarm.py — проверка сирены и отбоя.

⚙️ Технические детали
Система работает на флаг-файлах. Скрипты мониторинга создают пустые файлы (.flag), а плеер их считывает и удаляет. Это позволяет избежать конфликтов при одновременном доступе к аудио-карте.

FLAG_ALARM — активная тревога (циклический звук).

FLAG_CANCEL — отбой (однократный звук).

FLAG_MOMENT — минута молчания (высокий приоритет).

Алгоритм создания файла через PowerShell:
Если хочешь создать его одной командой, выполни это:

PowerShell
Get-Content -Path "C:\kyiv_alert\README.md" # Проверить текущий (если есть)
# Или просто вставь текст выше в новый файл через Блокнот.

1. Подготовка терминала (PowerShell)
Для каждого скрипта нужно открыть отдельное окно PowerShell. Чтобы не возникло проблем с правами доступа (как при ошибке UnauthorizedAccess), запустите PowerShell от имени администратора.

2. Очередность запуска
Шаг 1: Запуск Плеера (Обработчик звука)
Это «сердце» системы. Он должен работать первым, чтобы не пропустить флаг от других скриптов.

PowerShell
& "C:\kyiv_alert\venv\Scripts\python.exe" "C:\kyiv_alert\alert_monitor\player_service.py"
Что проверить: В консоли должны появиться зеленые галочки ✅ напротив всех аудиофайлов. Статус должен смениться на 💤 Ожидание событий.

Шаг 2: Запуск Монитора (Связь с API)
Этот скрипт начинает проверять реальный статус тревоги в Киеве.

PowerShell
& "C:\kyiv_alert\venv\Scripts\python.exe" "C:\kyiv_alert\alert_monitor\monitor.py"
Что проверить: Должна появиться таблица с текущим временем и статусом ⚪ ЯСНО | API: OK.

Шаг 3: Запуск Планировщика (09:00)
Скрипт, который отвечает за минуту молчания.

PowerShell
& "C:\kyiv_alert\venv\Scripts\python.exe" "C:\kyiv_alert\alert_monitor\moment_scheduler.py"
Что проверить: Скрипт напишет время, оставшееся до следующего запуска (ближайшие 09:00).

3. Схема взаимодействия компонентов
Монитор и Планировщик — это «глаза». Они только смотрят и создают маленькие файлы-записки (.flag).

Плеер — это «руки». Он постоянно проверяет папку, забирает «записку», включает звук и выбрасывает «записку» (удаляет файл).

💡 Советы по эксплуатации
Не закрывайте окна: Если закрыть окно monitor.py, вы перестанете получать данные о тревогах. Если закрыть player_service.py — звук не включится.

Спящий режим: В настройках Windows (Питание и спящий режим) установите "При питании от сети переводить компьютер в спящий режим через: Никогда". Если компьютер "уснет", Python перестанет работать.

Громкость: Проверьте, что в микшере громкости Windows звук для Python выставлен на максимум и колонки включены.
